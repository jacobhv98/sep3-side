Her ser du SEP3-gruppens opgaver, projektfiler, aktivitet og beslutninger fra det private repo. Siden gemmer ingen data selv. Alt hentes fra GitHub med dit eget token, så kun gruppens medlemmer kan se noget.

  1. Lav et klassisk token på GitHub med scopet repo og en udløbsdato.
  2. Tryk på Log ind med token, og indsæt det.
  3. Tokenet gemmes kun i din egen browser og forlader den aldrig andet end til GitHub.
